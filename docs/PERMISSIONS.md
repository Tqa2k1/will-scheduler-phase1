# PERMISSIONS.md — 権限

ロール: ADMIN / INC（`isManagerRole`＝管理者側）/ EMPLOYEE。認証は NextAuth（JWT）。権限は**API側で必ず検査**する。

| 操作 | ADMIN/INC | EMPLOYEE |
|---|---|---|
| 勤務表の編集・ASK①/②・メール配信・AI依頼・一括確定 | ○ | × (403) |
| 月別の勤務希望登録の停止/再開 | ○ | ×(403) |
| 登録停止状態の参照（GET registration-hold） | ○ | ○ |
| 勤務希望の登録・自分の取消 | × | ○（本人のみ。停止中は登録・変更不可） |
| 取消申請の承認／却下、申請の承認／却下 | ○ | × |
| アカウント設定（従業員情報の閲覧・編集・追加・削除、優先順位） | ○ | ×(403・`/users`は`/account/password`へ誘導) |
| アカウント設定（ログインアカウントの作成・削除・紐付け） | ADMINのみ（INCは403） | × |
| スケジュール設定（スケジュール・勤務時間設定） | ○ | × |
| パスワード変更（自分のみ） `/account/password` | ○ | ○ |
| 勤務表の閲覧 | 常に全員分 | 「確定」月のみ全員分（氏名・シフト時間のみ）。調整中はデータを返さない |
| Excel/PDF出力 | 常に可 | 確定月のみ（調整中は403） |
